Error codes

Each CamusDB error has a code and a message. The drivers show the code on their error objects, for example the .NET driver. Use this page to look up a code that you see in a log or a response.

You should base application logic on the code. The message is for people, and it can change. For example, replay a transaction with a retry helper on CADB0502 or CADB0504. On a CADB03xx constraint failure, show the user a validation error.

Error envelopes for protocol clients

A failed HTTP response looks like this:

{
  "status": "failed",
  "code": "CADB0400",
  "message": "error message"
}

Unary and streaming gRPC calls carry the same domain code in the camus-error-code trailer. A gRPC batch operation carries the code in its BatchError message.

Code ranges​

RangeArea
CADB00xxCatalog, metadata, and storage state.
CADB03xxData integrity constraints.
CADB04xxInvalid SQL and invalid input.
CADB05xxTransactions, schema, and statement limits. CADB051x is authentication and grants.
CADB06xxConfiguration.
CADB07xxBackup and point-in-time recovery.
CADB08xxC# extensions, and detected storage damage (CADB0837). The transaction errors CADB0847 and CADB0849 are also in this range.

Most codes are errors that users see. Some codes report corruption or an unexpected internal state. See Corruption and internal-state errors.

CADB0302ValueTooLongA STRING or BYTES value is longer than the maximum length of the column.
CADB0303CheckConstraintViolationA row would break a check constraint, also when the constraint is added. An error in the check expression, such as a regex failure, also returns it.

CADB0402DuplicatePrimaryKeyReserved for duplicate primary keys. The storage path usually returns CADB0300.
CADB0403DuplicateColumnA column name is repeated, in any case, for example in a schema definition or an INSERT column list. A rename to an existing column name also returns it. HTTP 400.
CADB0404UnknownColumnA statement references a column that doesn't exist or isn't visible.
CADB0405UnknownKeyA named index doesn't exist in the table, for example in a FORCE_INDEX hint. In other cases, it points to an internal mismatch.
CADB0406SqlSyntaxErrorThe SQL can't be parsed. The message gives the line and column.

CADB0408SchemaLimitExceededA name is longer than max_identifier_length, or a schema change would pass a schema limit, such as max_columns_per_table.

CADB0415InvalidForeignKeyDefinitionA foreign key has an invalid target, for example a wrong column type or a view.
CADB0416ForeignKeyCycleA foreign key would create a cycle across two or more tables. A table can reference itself.
CADB0417NumericValueOutOfRangeA NUMERIC value or result is outside the supported range, ±99999999999999999999999999999.999999999.
CADB0418InvalidJsonTextThe text of a JSONB value isn't a valid document, for example invalid JSON or a \\u0000 escape. HTTP 400. See JSON documents.
CADB0419JsonNestingTooDeepA JSONB document nests more than 512 levels. HTTP 400.
CADB0420IntegerValueOutOfRangeAn integer value or result is outside INT64 or the column range. Use NUMERIC for wider exact values. HTTP 400; gRPC OUT_OF_RANGE.
CADB0421FloatValueOutOfRangeA finite float value or result overflows, or underflows to zero. HTTP 400; gRPC OUT_OF_RANGE.
CADB0422JsonbValueTooLargeA built JSONB aggregate is larger than 268,435,455 bytes. HTTP 400; gRPC INVALID_ARGUMENT.
CADB0423InvalidIndexExpressionThe expression can't be used as an ordered index key. See Expression indexes. HTTP 400. gRPC INVALID_ARGUMENT.
CADB0501TransactionAlreadyCompletedA commit or rollback names a transaction that isn't active. Kahuna, the storage layer, also returns it for a permanent commit failure of a dead transaction.
CADB0502TransactionConflictA lock conflict or a conflicting concurrent write, or a schema change since the transaction started. The message can name the table and some contended keys. Retry from BEGIN.
CADB0503SchemaCatchingUpThe node is more than one schema version behind for the database. Retry later, or on another node.
CADB0504TransactionMustRetryA transient condition used up the internal retries, for example a leader change or a lock-wait deadline. Retry from BEGIN.
CADB0505TransactionLifetimeExceededA serializable read-write transaction was open longer than max_serializable_transaction_lifetime_ms (default one hour). Retry from BEGIN.
CADB0506TransactionMutationLimitExceededA transaction would pass the mutation limit (default 20,000 row and index mutations). Split the work. A retry fails again.
CADB0507SpillStorageUnavailableAn operator needed spill files, but the spill directory or a file couldn't be created. Free disk space, or fix the permissions under data_dir.
CADB0508DatabaseHasLiveDescendantsDROP DATABASE of a database with live branches. Drop the branches first.
CADB0509TransactionFinalizeUnresolvedA COMMIT or ROLLBACK doesn't have a final answer after the internal retries. Send the same request again on the same transaction. Don't replay the work.
CADB0510OrphanNotFoundA RELINK TO or a reclamation names an orphan id that doesn't exist, or that was already recovered or reclaimed.
CADB0511CommentTooLongA comment is longer than 65,535 characters.
CADB0512UserAlreadyExistsCREATE USER names a user that exists, and the statement doesn't have IF NOT EXISTS.
CADB0513UserDoesNotExistA user statement or a grant names a user that doesn't exist. GRANT doesn't create users.
CADB0514UnsupportedAuthPluginIDENTIFIED WITH names an unsupported plugin. Only sha256_password is supported.
CADB0515InvalidPrivilegeGRANT or REVOKE names an unknown privilege, or a privilege that isn't valid for the scope.
CADB0516AuthenticationFailedThe credentials aren't valid, for example a wrong password or an expired token. Unknown users and wrong passwords get the same error.
CADB0517InsufficientPrivilegeThe caller doesn't have a privilege that the statement needs, also on tables that joins and subqueries read.
CADB0518TooManyAuthAttemptsThe sign-in rate limit, or the password-check concurrency limit, refused the attempt.
CADB0519InsecureTransportA request with credentials arrived over plaintext while authentication and TLS are required. Use https://, or configure a trusted TLS proxy.
CADB0520UnknownPreparedStatementA prepared statement handle isn't known, for example after a restart, or on another node. Prepare again and replay once.
CADB0521PreparedStatementLimitExceededA prepared statement would pass a limit, such as the count limit. Close unused handles, or change the limits.
CADB0522AnalyzeRequiresNoPendingWritesANALYZE executed in a transaction with uncommitted writes. Commit or roll back first.
CADB0523ViewDoesntExistA view or materialized view doesn't exist, or the statement is for the other kind, such as DROP VIEW on a materialized view. SHOW STATISTICS FOR on a view also returns it.
CADB0524ViewAlreadyExistsA view or a materialized view already has the name of a new object. A table name returns CADB0013.
CADB0525ViewNotUpdatableDML was issued against a view that can't be written through, or against a materialized view. The message names the rule that the view breaks. See Write through a view.
CADB0526ViewColumnNotUpdatableA write through a view targets a computed column. The column doesn't have a base column to write.
CADB0527ViewCheckOptionViolatedA row written through a view WITH CHECK OPTION isn't a row of the view. A condition that is NULL also fails. See WITH CHECK OPTION.
CADB0528ViewRecursionDetectedThe dependencies of a view form a cycle. This is detected at DDL time.
CADB0529CannotChangeViewShapeCREATE OR REPLACE VIEW changes the existing columns of the view. Only new columns at the end are allowed.
CADB0530DependentObjectsExistA schema change would remove the target of a dependent object, for example of a view or a foreign key. Drop the dependent object first.
CADB0531MaterializedViewNotPopulatedA read of a materialized view that was created WITH NO DATA and wasn't refreshed. This prevents an empty result by mistake.
CADB0532RefreshAlreadyInProgressA REFRESH of the materialized view is already in progress, on any node.
CADB0533FeatureNotSupportedA statement that parses but isn't supported, such as REFRESH MATERIALIZED VIEW ... CONCURRENTLY. The message names the missing capability and the form that works.
CADB0534ConcurrentSchemaChangeA definition changed while an operation derived a new one from it. The operation wasn't applied. Execute it again.
CADB0535SequenceUnavailableA counter, such as a table id, couldn't be reached: its partition had no confirmed Raft leader during sequence_retry_budget_ms. No value was allocated. HTTP 503. Retry.
CADB0536InsufficientDiskSpaceFree space on the data volume is below min_free_disk_bytes, and the write was refused. Reads and DDL continue to work. HTTP 507.
CADB0537SnapshotPrecedesContentsGenerationAn AS OF SYSTEM TIME read names a point before a TRUNCATE of the table. Read at or after the truncate, or recover the old contents with RELINK TO.
CADB0538StatementNotAllowedInTransactionA schema statement can't run in the current explicit transaction. See Transactional schema changes for supported operations.
CADB0539BranchSnapshotProtectionLostA branch lost the snapshot protection of its inherited history. Create the branch again. HTTP 410.
CADB0542SequenceAlreadyExistsA sequence already has the name of a new object.
CADB0543SequenceDoesntExistThe sequence doesn't exist.
CADB0544SequenceExhaustedThe sequence doesn't have a value left before its MAXVALUE.
CADB0545InvalidSequenceDefinitionThe sequence definition is invalid, for example a negative increment or a START outside the range.
CADB0546SequenceValueNotYetDefinedcurrval or lastval before the transaction drew a value.
CADB0547SequenceCallNotAllowedHereA sequence call is in a position where the number of values isn't known before the statement executes.
CADB0548SequenceInUseAn identity column owns the sequence, or a column default uses it.
CADB0549SpillLimitExceededA spill write would pass spill_max_total_bytes on this node. The statement fails, and its spill files are deleted.
CADB0550ReturningResultTooLargeThe RETURNING rows of a write don't fit in one gRPC non-query reply. The statement rolls back. Use a streaming query, or ask for the row count only.
CADB0551QueryNotFoundCANCEL QUERY didn't find a visible running query with the id.
CADB0552QueryNotCancellableCANCEL QUERY named a statement that can't be stopped now, for example a write.
CADB0553QueryOwnerUnreachableThe node that can own the query didn't answer before the cancel timeout. The query can continue to execute.
CADB0554QueryCancelledA statement was stopped by CANCEL QUERY. The rows returned before the error are real rows.
CADB0555LockNotAvailableFOR UPDATE NOWAIT found a locked row. HTTP 409; gRPC ABORTED. It isn't retried automatically.
CADB0556ResultSetTooLargeA buffered result passed its row or memory limit. The statement rolls back. HTTP 400; gRPC RESOURCE_EXHAUSTED.
CADB0557StatementTooLargeInline SQL was larger than max_statement_bytes. HTTP 413; gRPC INVALID_ARGUMENT.
CADB0558ConcurrencyLimitExceededThe node reached its limit of explicit transactions or of cluster activity requests. Wait, then retry. HTTP 503; gRPC RESOURCE_EXHAUSTED.
CADB0559JsonbValueCorruptStored JSONB bytes don't decode. This means damaged data, or a value from a newer build. HTTP 500.
CADB0560RecursiveQueryLimitExceededA recursive CTE passed its step or row limit. Add a stopping condition, or change the recursive query limits. HTTP 400.
CADB0561TableFunctionRowLimitExceededA function in FROM produced more rows than max_table_function_rows. Narrow its arguments, or change the row limit. HTTP 400.
CADB0562StatementTimeoutA statement executed longer than statement_timeout_ms, and it was stopped. An autocommit statement rolls back. In an explicit transaction, the transaction becomes rollback-only. HTTP 400.
CADB0563ViewComplexityLimitExceededA view definition, or the view expansion of a statement, is over a view limit, such as max_view_expanded_relations. The message names the setting. HTTP 400. See Size limits.
CADB0564TooManyTablesInStatementA statement reads more tables than max_tables_per_statement, with the tables of subqueries and view bodies. HTTP 400.
CADB0565TransactionKilledKILL TRANSACTION ended this transaction. It's rolled back. Its next statement and its COMMIT fail, and a ROLLBACK of it succeeds. Begin a new transaction. HTTP 409 / gRPC FAILED_PRECONDITION. It isn't retried automatically.
CADB0566TransactionNotFoundKILL TRANSACTION didn't find an open transaction with that id that the caller can see. The transaction ended, or the id is wrong. A transaction of another user also gives this error. HTTP 404.
CADB0567TransactionOwnerUnreachableThe node that can own the transaction id didn't answer before the timeout. The transaction can be open. Send the kill again. HTTP 503.
CADB0568TransactionKillPendingKILL TRANSACTION ended the transaction, but its rollback didn't end yet. One of its statements executes now, or the rollback is in progress. The rollback releases the locks when it ends. Send the kill again to confirm. HTTP 409 / gRPC DEADLINE_EXCEEDED.
CADB0569TransactionKillRollbackFailedKILL TRANSACTION ended the transaction, but its rollback failed. The transaction can't run more statements or commit. The storage node releases its locks when the session of the transaction expires. The same kill returns this code again. HTTP 500 / gRPC INTERNAL.
CADB0600InvalidConfigThe configuration is invalid, for example an unknown key or an invalid value. At runtime, a SET CLUSTER SETTING value that breaks a rule between two settings also returns it. The setting isn't changed.
CADB0847SnapshotTooOldRetention removed history that a snapshot read needs. HTTP 409. Use a newer timestamp or a new transaction.
CADB0849ReadOnlyTransactionA write, or nextval() or setval(), in a read-only transaction. The statement doesn't change anything, and it aborts the transaction. HTTP 400; gRPC FAILED_PRECONDITION. See Read-only transactions.

Only the backup and point-in-time recovery administration API raises CADB07xx codes. Each code maps to a specific HTTP status. See Backup And Restore for the full reference.

CodeNameWhen it is generated
CADB0700BackupNotConfiguredA backup or restore was requested but kahuna.backup_dir is unset. Backups are opt-in.
CADB0701BackupChainInvalidA backup chain does not start at a full backup, has a gap or broken parent link, or contains a cycle.
CADB0702BackupNeedsFullBackupAn incremental backup's parent fell below the retention floor. A contiguous increment isn't possible.
CADB0703RestorePointOutOfWindowThe requested restore point lies outside the chain's recoverable coverage.
CADB0704RestoreFailedA restore failed while copying the base image or replaying the write-ahead log (WAL).
CADB0705BackupParentMissingThe parent backup named by an incremental request does not exist.
CADB0706BackupCorruptArtifactAn artifact doesn't match the manifest, for example a missing file or a wrong digest.
CADB0707RestoreTargetConflictThe restore destination exists, or it overlaps a path in use, such as the live data root.
CADB0708BackupExactCheckpointUnavailableThe storage backend cannot produce an exact as-of checkpoint at the requested cut.
CADB0709BackupUnsupportedFormatA manifest or artifact is in a legacy or unsupported format.
CADB070ABackupRetryableLeadershipLossPartition leadership was lost mid-operation. No durable change was applied.
CADB070BBackupCancelledThe caller cancelled the operation.
CADB070CRemoteRestoreDisabledNo kahuna.restore_root is configured and the unconfined opt-in is off.
CADB070DBackupTopologyChangedCluster topology changed during a coordinated backup. The captured partitions aren't one consistent cut, and the backup isn't published.
CADB070EBackupNotCoordinatorA coordinated backup was requested on a node that does not lead the backup meta partition.
CADB070FBackupInsecureRootThe backup or restore root is a symlink, or is group- or world-writable.
CADB0710PitrBootstrapFailedA joining node could not seed itself from a restored backup chain. The restored data root may be missing, its WAL may not be empty, the chain or MAC may be invalid, or the seeded point may be outside the leader's retained log window.

Retry guidance​

You can usually retry after these codes:

  • CADB0502 TransactionConflict
  • CADB0503 SchemaCatchingUp
  • CADB0504 TransactionMustRetry
  • CADB0505 TransactionLifetimeExceeded
  • CADB0516 AuthenticationFailed after obtaining fresh credentials
  • CADB0518 TooManyAuthAttempts after waiting for the rate-limit window
  • CADB0520 UnknownPreparedStatement after preparing the statement again
  • CADB0532 RefreshAlreadyInProgress once the running refresh finishes
  • CADB0534 ConcurrentSchemaChange after re-reading the current definition
  • CADB0535 SequenceUnavailable once the partition's election settles
  • CADB0536 InsufficientDiskSpace after freeing disk space or lowering the threshold
  • CADB070A BackupRetryableLeadershipLoss once a leader is elected
  • CADB070D BackupTopologyChanged once cluster membership is stable

CADB0509 TransactionFinalizeUnresolved needs a different kind of retry: send the same COMMIT or ROLLBACK again for the same transaction id. Don't start a new transaction or replay the statements. The original commit can already be applied on the server.
